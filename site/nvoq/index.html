  • Senior Software Engineer & Technical Lead - Developer Tooling (2023-2025) Python • C++ • OpenFst • Thrax • Kaldi • AWS • Docker • Jenkins

    I developed a Python package, backed on C++ extensions using pybind11, for language and acoustic modeling and text processing. The package exposed an intuitive interface to the low-level, high-concurrency code used to compile text corpora, pronunciation lexicons, and regex-like text processing grammars into finite-state transducer models. The package also improved the workflow for building acoustic models with Kaldi's neural network libraries. These tools enabled nVoq's data scientists and lingusitics to more efficiently make improvements to our speech recognition models without low-level C++ and Bash expertise required on their part.

    In conjunction with this work, I architected the migration of on-prem model build systems to containerized infrastructure in AWS using Docker, GitLab CI/CD, and Jenkins. These updates moved the builds off persistent servers running Bash code that was notoriously difficult to modify and improve and on to the Python package mentioned previously. This migration improved build reliability by ~4x and decreased model compilation times by ~80%.

    During this period, I also served as the primary maintainer of the core text processing utilities mentioned above, managing complex domain-specific Thrax grammars (similar to regex) compiled to finite-state machines via OpenFst. These grammars were used for low-latency text normalization (for preparing large text corpora for n-gram modeling) and inverse normalization (for real-time formatting of the speech recognizer's output in production). I built a lexer and syntax highlighting VS Code extension for the grammar DSL, and enhanced its compiler's import system to allow for better organization and DRY in the grammar files.

    At the start of this period, I also trained four team members on our modeling systems, and throughout the period I worked with our product owners to plan and prioritize the team's tasks. I had become nVoq's effective SME on hybrid speech recognition systems by this point, and wrote extensive documentation of our modeling systems to facilitate developer productivity and future onboarding.

  • Senior Software Engineer - High-Performance Servers (2021-2023) C++ • Java • JNI • GStreamer • Kaldi

This server handled ~20x the number of requests for the same memory usage as the previous generation.

I also worked with DevOps to ensure smooth server deployments, maximize uptime, and optimize load balancing.

    This server was just the primary in a handful of other services the team developed at this time. We also built a low-overhead HTTP-to-WebSocket router, formalized the dictation server's HTTP interactions with the database and administrative service, and created a specialized audio proxy service that routed mobile microphone input streams to the dictation server while routing the resulting text to the user's PC, allowing for more flexible usage of the speech recognition process on their part.
