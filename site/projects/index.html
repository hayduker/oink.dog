Personal Projects

  • Open source contributions (current) Rust • Python • CRDTs • distributed systems A deep-dive into modern systems programming in Rust, with an emphasis on projects related to p2p networks, DHTs, local-first data storage, and cryptographic primitives. I'm currently learning about CRDTs and have made a few contributions to Holochain, Automerge, and Iroh.
  • whipsnake (current) Rust • Python • WebAssembly An ahead-of-time compiler targeting WebAssembly for a strict subset of Python syntax. I implemented a hand-written lexical analyzer, recursive-descent parser, abstract syntax tree generator, and evaluator to begin with. The interpreter supports literals, operators, control flow, loops, and functions. I'm actively researching WebAssembly for code generation and potentially a basic Wasm runtime as well. Inspired by Robert Nystrom's Crafting Interpreters.
  • keith-shareit (2026) Rust • Iroh • Ratatui A peer-to-peer media transfer library written using a collection of Iroh's tools. Supports mDNS for automatic discovery of devices on the same LAN, or Iroh's ticketing system for connection across broader networks. Built on a filesystem store to minimize RAM consumption during transit.
  • Open source contributions (2025) Mojo • Python I made a few contributions to the standard library and documentation for the Mojo programming language, as well as some early architectural changes to the Python API client for the Anytype local-first personal knowledge management system.
  • Monkey compiler (2024) Python • Monkey Two implementations of the Monkey programming language from Thorston Ball's books: a tree-walking interpreter, and a bytecode compiler and accompanying stack-based virtual machine to run it. This was my first compiler project as I was deep-diving into Python at nVoq, so I wrote it in that rather something more, uh, suitable.
  • Moreno music map (2020) JavaScript • Spotify API A client-side data visualization app built on the D3.js framework and the Spotify API. It allows user to discover new music based on their existing favorites by displaying a force-directed graph built from artist interconnections. Previews of artists' music can be played in the browser by clicking on the nodes.
